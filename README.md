## 🧩 What is this?

A real-time AI system that converts your **hand gestures into game controls** using a webcam.

Play games like:
- 🏃 Subway Surfers  
- 🐒 Temple Run  
- 🎮 Other browser-based games  

No keyboard required.

---

## 🔥 Why this project?

- Gesture-based interaction  
- No external hardware needed  
- Fast and lightweight  
- Real-time response

## 🎯 Gesture Controls

| Gesture | Action |
|--------|--------|
| 👍 Thumb Up | Move Left |
| 🤙 Pinky Up | Move Right |
| ✋ Open Hand | Jump |
| ✊ Fist | Slide |

| Technology | Purpose |
|------------|--------|

| OpenCV | Image processing |
| MediaPipe | Hand tracking |
| CVZone | Detection wrapper |
| PyAutoGUI | Keyboard control |
